## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding (e.g. `.v-body` padding) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: 6px (button gaps, form fields), 10px (nav items, card headers), 14px (card head padding, top actions) as established in `src/styles.css`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0c11` | Background (`--bg`), main surfaces |
| Secondary (30%) | `#1a1f28` | Cards, sidebar, nav (`--surface-2`) |
| Accent (10%) | `#34d399` | Primary CTAs, active progress bars |
| Destructive | `#f87171` | Destructive actions, error states |

Accent reserved for: Primary action buttons (e.g., Run Backup), healthy status dots, active progress bars, and "on" state toggles.
