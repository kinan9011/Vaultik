# Requirements

## CORE (Core Functionality)
- CORE-01: Ensure robust error handling for failed restic backup runs.
- CORE-02: Implement real-time progress parsing and display during backup runs.
- CORE-03: Support multiple backup profiles with distinct configurations.

## SCHEDULING (Automation)
- SCHED-01: Allow users to configure cron-based backup schedules per profile.
- SCHED-02: Execute scheduled backups in the background without requiring the UI to be open.

## RESTORE (Data Recovery)
- REST-01: Browse snapshots with hierarchical file tree view.
- REST-02: Restore selected files/folders to a specified destination.

## SETTINGS (Configuration)
- SET-01: Manage global application settings (theme, startup behavior).
- SET-02: Configure restic binary path and global environment variables.

## POLISH (UI/UX)
- POL-01: Add system tray icon for background status.
- POL-02: Implement native system notifications for backup completion/failure.
